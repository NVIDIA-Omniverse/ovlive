# Fixture provenance

`synthetic.json` contains zlib-compressed base64 OMPF containers generated by `scripts/regenerate-conformance-assets.py` and `oodf-ffi/examples/conformance_fixture.rs`.
The large fixture holds a compressible 2 MiB value.
`captured.json` is copied from the committed Kit traffic at `tools/fixtures/gze_inbound_deltas.json`.
Replay selects the final CreateLayer and its following updates, matching the acceptance harness's generation selection.
The capture has no time samples; synthetic cases cover that dimension.
`captured-golden.json` is the committed C++ reference result from `tools/fixtures/gze_cpp_catchup_oracle.json`; its normalized final state is an independent oracle, not a response from the implementation under test.
The synthetic `structure` edit explicitly creates, moves, deletes and reorders sections; its expected result is pinned in the test.
`../build.json` records input hashes, including the public protobuf and OODF schema.
